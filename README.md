# Little Sea Snake's Ocean Mission

A sea-snake game for 4th graders to practice the Present Continuous (am / is / are + V-ing).
English UI by default, with a 繁體中文 toggle. Single HTML file, illustrations generated with ComfyUI.

Play: https://nice923boss.github.io/little-sea-snake-mission/
